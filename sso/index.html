Planned Access Flow

  1. User selects Login from Facilities Engineering.
  2. Site redirects the user to the approved SSO provider.
  3. Provider validates identity, MFA, and group assignment.
  4. User returns to the authorized Facilities Engineering resource.
  5. Access events are logged according to team policy.
